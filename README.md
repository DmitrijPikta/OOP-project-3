# OOP project 3

### Instruction to install aplication:
1. Download file .exe or .msi
2. Run it
3. Finish installation

### Important to know:
Aplication read and write text files in user documents folder. When you install aplication, two text files are installed automatically. They are in your document folder with names "t10.txt" and "t100.txt". "t10.txt" file have 10000 students and "t100.txt" file have 100000 students. You can use them or create your own text files.
